# Experiments

A suite of small experiments that serves as empirical evidence and basis of the performance-oriented decisions I have made throughout the project.

> [!NOTE]
> The code found in this directory is not representative of the code used in the actual database. Rather, the code in this directory is meant to be small and isolated and is meant for observation and measurement of patterns, designs, strategies, and etc. for the purposes of guiding decision making in the actual database.
